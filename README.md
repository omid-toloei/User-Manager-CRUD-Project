# User Manager

A simple CRUD User Manager application built with HTML, CSS, and JavaScript. The project currently supports creating and displaying users while serving as a practice project for working with forms, DOM manipulation, Fetch API, and REST APIs.

## Features

- Display user list
- Form validation
- Responsive user interface
- Clean and organized code structure
- loader spinner
- error handling

## Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
- Fetch API

## Purpose

This project was created to practice JavaScript fundamentals and understand how CRUD applications communicate with REST APIs.
